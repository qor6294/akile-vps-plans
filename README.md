## 5Gbps 端口不等于你能跑 5Gbps

5Gbps 是端口上限，1TB 是每月流量上限。1TB 按 5Gbps 满速跑，二十几分钟就消耗完了。

建站、跑 API、看视频这类场景很难碰到端口上限，大端口带来的是单次传输快，不是能一直满速跑。真正决定够不够用的是月流量那一栏。反过来说，如果你要拿它做持续大流量的中转、长期挂下载或做镜像分发，1TB 一个月不算多：洛杉矶 LAXLite-Starter ¥34.99 给到 5TB，新加坡 SGLite-Standard ¥87.49 给到 6TB。

这条比价格更该先看。Akile 台湾 1 核 2G / 1Gbps 那档（¥24.99/月，2.5TB 流量）的规则是：流量用完后端口限速到 **10Mbps**，重置流量 20 元。

10Mbps 还能开网页、跑 SSH、收邮件，比直接断网友好。但也到此为止，限速状态下看视频、传大文件都不现实。

其他档位的超量规则没有逐条核到，下单页的流量说明值得花两分钟读完。低价 VPS 圈里常见的做法是限速到 1Mbps 左右，那个速度基本等于不能用。别默认所有套餐的超量处理方式都一样。

## 下单前该确认的几件事

- **支付方式**。结账页支持哪些渠道，自己看一眼比问人快。
- **退款政策**。买了不满意能不能退、几天内退。低价套餐很多明确不退款。
- **IPv4 是独立还是共享**。NAT 款只有共享 IPv4，需要独立 IP 建站、发邮件的场景会受限。
- **换 IP 政策**。台湾那档的说明里写了可以申请更换 IP，其他机房是否同样，单独确认。
- **硬盘扩容价格**。台湾档是 5 元 / 10GB，其他机房标准不同。
- **Pro 和 Lite 的网络差别**。官方说明不一定写全，下单页的线路描述比套餐名可靠。

## 哪些人不该买

要跑生产数据库、需要 SLA 赔付、出问题要求工单分钟级响应的，低价月付机不是为这类场景设计的。小商家在客服响应和超售控制上普遍吃力，工单排队几小时到一天是常见情况，晚高峰性能打折也不罕见。这类需求应该看有明确 uptime 承诺和托管服务的方案，价格会是这里的几倍。

另一种不适合：需要长期稳定的独立 IP 和固定带宽跑业务。NAT 款和共享资源的套餐不匹配这类需求。
